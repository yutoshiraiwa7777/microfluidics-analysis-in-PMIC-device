# microfluidics-analysis-in-PMIC-device
Microfluidic flow analysis using PTV in small intestine

## Overview
Python scripts for microfluidic flow analysis around intestinal villi.

## Files
- `plot_villus_nearest_neighbor_distance.py` : Visualization of nearest neighbor distance between villi under different pressure conditions
- `plot_particle_invasion_angle_polar.py` : Polar histogram of particle invasion angle toward villi (Far/Near classification)
- `plot_approach_velocity_toward_villi.py` : Analysis of particle approach velocity toward villi
- `plot_particle_trajectories_around_villus.py` : Visualization of particle trajectories around villus
- `plot_filtered_particle_trajectories_around_villus.py` : Filtered version of trajectory visualization
- `plot_cumulative_approach_displacement.py` : Comparison of cumulative approach displacement between deformation conditions
